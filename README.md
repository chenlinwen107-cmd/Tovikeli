# Tovikeli

**ACG · 兴趣社区 · 创作者 · 社交平台**

Tovikeli 是一款面向 ACG 社区、兴趣社区、创作者以及通用社交平台的现代化商业 SNS 源代码产品。

Tovikeli 为希望构建、定制或部署自有社交社区平台的开发者和团队提供实用的基础。

Tovikeli is a modern social-platform source-code product designed for ACG communities, interest-based communities, creators, and general-purpose social platforms.

It provides a practical foundation for developers and teams who want to build, customize, or deploy their own social community platform.

# 核心功能 | Core Features

Tovikeli 的设计理念是打造一个简洁、现代的社交平台源码模板，而不是以游戏化为核心的社区产品。

Tovikeli is designed as a restrained, modern social-platform source-code template rather than a gamification-heavy community product.

**核心能力 | Core capabilities**

- 用户账户和身份验证 · User accounts and authentication
- 社交动态 · Social feed
- 帖子和内容发布 · Posts and content publishing
- 帖子编辑和删除 · Post editing and deletion
- 图片和视频媒体 · Image and video media
- 用户个人资料 · User profiles
- 社交互动 · Social interactions
- 评论 · Comments
- 私信 · Private messaging
- 问答 · Questions and answers
- 主题和内容发现 · Topics and content discovery
- 搜索 · Search
- 面向创作者的内容功能 · Creator-oriented content features
- 管理功能 · Administrative functionality

Tovikeli 可作为以下类型平台的基础：

Tovikeli can serve as a foundation for:

- ACG communities
- Interest-based communities
- Creator platforms
- Content communities
- General-purpose social platforms
